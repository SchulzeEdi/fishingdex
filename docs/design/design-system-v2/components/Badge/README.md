# Badge

Selos curtos em caixa alta: plano, país e raridade.

- `fd-badge-free` / `fd-badge-pro`: plano no perfil. Corrige o selo FREE atual (branco sobre `surface-muted`, 1,2:1, invisível).
- `fd-flag`: código do país (BR, AR, US) no lugar do emoji de bandeira, que vira texto no Windows.
- `fd-rarity` + `fd-r-<nível>`: pips (1–4) + nome. A cor nunca é a única pista.

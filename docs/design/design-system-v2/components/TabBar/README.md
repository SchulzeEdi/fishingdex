# TabBar

Navegação inferior com 5 posições e o FAB "Registrar" no centro.

- Altura `tabbar-height` + safe area, fundo `surface`, `shadow-md`. Ícone 24px + rótulo `caption`; ativo em `primary`.
- FAB `fab-size` em `primary`, elevado `space-lg` acima da barra com aro na cor `background`; abre o fluxo de registrar.
- Ícones: `feed`, `trophy`, `plus`, `fish`, `user` — no lugar dos emojis atuais.

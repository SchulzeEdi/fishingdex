# DexProgress

Progresso da coleção no topo da Dex: número grande + barra.

- Número capturado em Sora 30 tabular, total em `text-muted`, percentual em `primary`.
- Barra 8px, trilho `surface-muted`, preenchimento `primary`. `role="progressbar"` com valores.
- Mostre o progresso do habitat selecionado no `SegmentedControl`.

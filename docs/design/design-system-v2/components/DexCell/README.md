# DexCell

Célula da coleção de espécies, em grade de 3 colunas.

- **Desbloqueada:** arte/foto 1:1, `Nº 001`, nome, raridade com pips.
- **Bloqueada** (`is-locked`): fundo `surface-muted`, borda tracejada `border-strong`, silhueta em `silhouette`, cadeado pequeno, nome `???` — o número aparece, o nome não.
- **Recém-desbloqueada** (`is-new`): anel `accent` + selo "Nova" até o usuário abrir a ficha.
- O consumidor fornece número, nome no idioma atual, raridade, foto e estado. Toque abre a ficha da espécie.

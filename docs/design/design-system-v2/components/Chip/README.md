# Chip

Etiqueta compacta de dado: setup da captura, habitat, filtro.

- `fd-chip`: rótulo em `text-muted` + valor em `<b>` (`text`). Para setup: "Isca **Zara**".
- `fd-chip-water`: habitat, contorno e texto `accent-ink` com ícone.
- `fd-chip-filter`: filtro tocável do ranking (`aria-pressed`); ativo inverte para `text` sobre `background`.
- "Local privado" é um `fd-chip` com o ícone `lock`.

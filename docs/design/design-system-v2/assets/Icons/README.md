# Icons

Conjunto próprio do fishingdex, 24×24, traço 1,75, pontas e cantos arredondados. Tinta única `#0b1f24` (o `text` claro): no app troque o `stroke` pela cor do tema; nos previews use `fd-icon fd-i-<nome>`, que herda a cor do texto.

- `feed.svg` — aba Feed (ondas). `trophy.svg` — aba Ranking. `plus.svg` — FAB Registrar. `fish.svg` — aba Dex e habitat água doce. `user.svg` — aba Perfil.
- `heart.svg` / `heart-fill.svg` — curtir / curtido (`danger`). `star.svg` / `star-fill.svg` — Pro.
- `lock.svg` — bloqueado e local privado. `map-pin.svg` — local/pesqueiro. `ruler.svg` — tamanho. `camera.svg` — foto/registrar.
- `search.svg`, `check.svg`, `chevron-right.svg`, `alert.svg` (erro), `wifi-off.svg` (sem conexão), `message.svg` (contato no WhatsApp).
- `fish-silhouette.svg` — forma preenchida (64×40, tinta `#2a3f47` = `silhouette` claro) para a célula bloqueada da Dex e placeholder de foto.
